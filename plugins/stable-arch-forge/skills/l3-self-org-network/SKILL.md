# 自组织协同层组网设计技能

## 1. 架构来源引用

> 引自 `../docs/03_full_detail_design.md`

自组织协同层：Agent 邻域组网、任务分片、标准化消息通信。Agent 仅允许邻域交互，禁止无边界跨模块直接耦合。

- Agent 通信：标准化消息体，消息包含来源、目标、载荷、校验哈希。
- 邻域组网：Agent 仅与直接邻域 Agent 交互，长距离任务流转经由目标场调度。
- 任务分片：单个大目标拆分为多个邻域子任务，分配到对应 Agent。
- 冲突处理：Agent 之间出现冲突时，提交巡检 Agent + 架构 Agent 评审，**不能自行突破边界解决冲突**。

## 2. 输入条件

- L3-01 `l3-target-field-design` 输出的 `layer_target_field_design.md`
- L2 规约与门禁文档

## 3. 分步执行动作

1. 读取架构自组织协同层详细设计。
2. 确认项目所需 Agent 角色集合。
3. 定义 Agent 邻域关系、消息结构、通信协议。
4. 设计任务分片机制、冲突处理流程。
5. 自查：Agent 之间不存在无边界直接跨模块耦合。

## 4. 输出物清单

- `layer_self_org_network_design.md`：自组织协同组网设计文档（角色 / 邻域 / 消息协议 / 分片 / 冲突处理）。

## 5. 门禁校验（强制）

> 全部满足才算通过；不通过不得进入 L3-03。

- [ ] Agent 通信遵守邻域交互约束，禁止全局无边界耦合
- [ ] 消息协议符合架构定义
- [ ] 冲突处理流程不允许 Agent 自行突破边界
