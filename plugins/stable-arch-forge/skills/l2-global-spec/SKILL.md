# 全局刚性规约落地技能

## 1. 架构来源引用

> 引自 `../docs/02_agent_dev_architecture.md`

全局刚性规约属于不可突破硬约束；所有上层设计、模块实现、Agent 工作产出，均不得违背规约。

1. 所有产出物（文档、设计、代码）必须可追溯到目标场中的目标。
2. 模块职责单向清晰，禁止职责重叠与跨模块隐式耦合。
3. 所有变更必须经过巡检层校验，重大变更触发架构评审。
4. 不在白名单内的技术、依赖默认禁止引入。
5. Agent 不能自行修改边界约束层规则。

## 2. 输入条件

- L1 全部技能门禁校验通过
- 插件内 `docs/02_agent_dev_architecture.md` 文档

## 3. 分步执行动作

1. 从架构基线提取全部全局规约原文，不修改语义。
2. 整理规约文档，区分强制项、禁止项。
3. 每条规约标注来源文档位置。
4. 确认规约没有新增架构以外自定义约束。

## 4. 输出物清单

- `project_global_spec.md`：项目全局刚性规约文档（强制项/禁止项/来源标注）。

## 5. 门禁校验（强制）

> 全部满足才算通过；不通过不得进入 L2-02。

- [ ] 所有规约条目全部来自架构基线，无自定义新增硬约束
- [ ] 每条规约都标记架构来源位置

## 6. 更新说明

原始架构规约修改（见 `docs/arch-version-log.md`），必须同步更新本输出物。
