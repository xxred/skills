# 稳态架构核心认知技能

## 1. 架构来源引用

> 引自 `../docs/01_meta_architecture.md`

本元架构借鉴生物稳态发育思想，用于 AI 多Agent协同软件研发。系统在持续迭代过程中保持整体结构稳态，防止模块越界、职责膨胀、边界模糊引发的**系统癌变**，形成闭环：输入 → 协同执行 → 状态检测 → 分级纠偏。

四层模型（自上而下）：**目标场层**（定义"要做什么"，统一约束下层）、**自组织协同层**（多Agent组网、邻域通信、任务分片）、**稳态巡检层**（持续采集状态、识别偏差与癌变风险）、**边界约束层**（刚性硬约束、门禁、白名单，底层防火墙）。

四大核心原则：①目标锚定原则；②边界刚性原则；③局部自治、全局可控；④前置检测、早期纠偏。
