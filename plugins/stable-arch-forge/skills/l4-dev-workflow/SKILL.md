# 全流程发育式开发执行技能

## 1. 架构来源引用

> 引自 `../docs/03_full_detail_design.md`

发育式开发阶段划分：目标场构建 → 全局规约与边界落地 → 四层架构设计 → 模块详细设计 → 编码实现 → 持续巡检纠偏回归。

> 发育式开发：迭代不是简单叠加功能；每一轮迭代都要维护架构稳态，持续巡检，防止腐化。

全流程闭环：目标场下发任务 → 自组织 Agent 协作产出设计/代码 → 巡检 Agent 持续扫描 → 分级处置偏差 → 完成校验，目标标记完成；如驳回，回流目标场调整需求/任务。

## 2. 输入条件

- L3 全部四层分层设计文档
- L2 规约门禁文档

## 3. 分步执行动作

1. 确认目标场内待执行目标，分配给对应 Agent。
2. 自组织 Agent 协同产出详细设计、代码、测试、文档。
3. 每一轮产出后，触发稳态巡检。
4. 根据巡检结果处理偏差，完成修复复核。
5. 校验全部门禁，目标标记完成；校验失败则回流目标场。

## 4. 输出物清单

- 迭代记录文档：开发迭代日志（目标、产出、巡检报告、处置记录）。

## 5. 门禁校验（强制）

> 全部满足才算通过；不通过不得进入 L4-02。

- [ ] 开发流程严格遵循发育式迭代顺序
- [ ] 每轮迭代都执行稳态巡检
- [ ] 所有产出物可追溯目标场目标

## 6. 更新说明

开发流程架构定义变更时同步更新技能。
