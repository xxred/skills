# 系统癌变与失控风险识别认知技能

## 1. 架构来源引用

> 引自 `../docs/01_meta_architecture.md`、`../docs/02_agent_dev_architecture.md`

**癌变**：系统迭代中突破边界约束，模块职责无限制扩张、职责越界、边界模糊、绕过规约，最终整体架构腐化失控。

- **普通偏差**：局部偏离预期，不突破边界，可局部修复（L1）。
- **严重偏差**：多处不一致，存在向癌变演化趋势（L2）。
- **癌变风险**：已经突破边界约束，模块越界，必须阻断、回滚重构（L3）。

癌变早期信号清单：职责越界、边界模糊、绕过规约、模块无限膨胀、引入未授权依赖。

## 2. 输入条件

- L1-01 `l1-arch-cognition` 门禁校验通过

## 3. 分步执行动作

1. 阅读架构文档中癌变、偏差分级全部描述。
2. 整理癌变早期信号清单：职责越界、边界模糊、绕过规约、模块无限膨胀、引入未授权依赖。
3. 建立区分标准：普通偏差 / 严重偏差 / 癌变风险。
4. 编写风险识别笔记，记录分级判定规则。

## 4. 输出物清单

- 风险识别笔记：偏差分级清单、癌变早期信号清单。

## 5. 门禁校验（强制）

> 全部满足才算通过；不通过不得进入 L2-01。

- [ ] 可以区分普通偏差、严重偏差、癌变风险
- [ ] 能列出至少 3 项癌变早期信号
- [ ] 理解癌变风险必须阻断的约束
