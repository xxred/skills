# 底层边界约束层落地设计技能

## 1. 架构来源引用

> 引自 `../docs/03_full_detail_design.md`

边界约束层设计要素：

1. **模块边界**：每个模块明确职责、暴露接口、禁止内部对外暴露。
2. **技术白名单**：语言、框架、包、工具清单。新增依赖必须申请评审。
3. **产物权限**：各类文档、设计、代码的读写权限归属。
4. **禁止项清单**：隐式全局状态、循环依赖、跨模块直接修改内部数据、绕过门禁。

## 2. 输入条件

- L3 前面所有分层设计文档
- L2-02 `boundary_gate_spec.md`

## 3. 分步执行动作

1. 读取架构边界约束层详细设计。
2. 划分系统模块，定义每个模块职责、对外接口、内部私有实现。
3. 定义模块之间允许/禁止的依赖关系。
4. 列出项目实例化禁止项清单。
5. 自查：所有边界约束不与 L2 门禁冲突。

## 4. 输出物清单

- `layer_boundary_design.md`：边界约束层详细设计文档（模块边界 / 接口 / 权限 / 禁止项）。

## 5. 门禁校验（强制）

> 全部满足才算通过；不通过不得进入 L4-01。

- [ ] 模块职责清晰，没有重叠模糊边界
- [ ] 明确区分对外接口和内部私有实现
- [ ] 禁止项清单对齐架构基线定义

## 6. 更新说明

边界层架构定义变更时同步更新技能。
