# 偏差识别与癌变分级处置技能

## 1. 架构来源引用

> 引自 `../docs/01_meta_architecture.md`、`../docs/03_full_detail_design.md`

分级处置流程：

1. **L1 普通偏差**：通知负责 Agent 就地修复，自动复核。
2. **L2 严重偏差**：暂停相关任务，提交专项修复计划，修复后人工复核。
3. **L3 癌变风险**：阻断当前迭代，评估是否需要回滚；由架构 Agent 牵头重构方案。

处置完成后复核，回流到目标场更新目标状态，形成闭环。

## 2. 输入条件

- L2 规约门禁文档
- L3 分层设计文档
- 稳态巡检报告（来自 L3-03 巡检体系）

## 3. 分步执行动作

1. 读取稳态巡检报告，识别问题，判定偏差等级（L1/L2/L3）。
2. L1 普通偏差：指派 Agent 就地修复，自动复核。
3. L2 严重偏差：暂停关联任务，制定修复计划，完成后人工复核。
4. L3 癌变风险：阻断当前迭代，评估回滚范围，架构 Agent 制定重构方案。
5. 全部处置完成，复核状态，记录处置记录。

## 4. 输出物清单

- `deviation_dispose_record.md`：偏差与癌变处置记录（等级 / 处置动作 / 复核结果 / 闭环状态）。

## 5. 门禁校验（强制）

> 全部满足才算通过；不通过不得进入 L4-03。

- [ ] 分级处置策略完全匹配架构定义，无自定义处置规则
- [ ] 所有处置都完成闭环复核

## 6. 更新说明

架构处置规则更新时同步修改本技能。
