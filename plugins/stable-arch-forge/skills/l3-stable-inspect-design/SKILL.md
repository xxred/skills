# 稳态巡检分层设计技能

## 1. 架构来源引用

> 引自 `../docs/03_full_detail_design.md`

稳态巡检层持续采集系统状态，执行五类检查：

1. **目标追溯检查**：产出物是否关联目标场目标。
2. **规约合规检查**：是否遵守全局规约。
3. **架构一致性检查**：实现是否匹配架构模型。
4. **边界越界扫描**：模块职责、依赖是否突破边界。
5. **技术栈白名单检查**：是否引入未授权依赖。

识别 L1 普通偏差、L2 严重偏差、L3 癌变风险，并触发分级处置（见 L4-02）。

## 2. 输入条件

- L3-01 `layer_target_field_design.md`、L3-02 `layer_self_org_network_design.md`
- L2 规约门禁文档

## 3. 分步执行动作

1. 阅读架构巡检层详细设计。
2. 为本项目实例化巡检检查清单（五类）。
3. 定义每一类检查对应的判定规则，绑定偏差分级。
4. 设计巡检触发时机：迭代中自动巡检、重大变更强制巡检。
5. 确认巡检规则不绕过底层边界约束。

## 4. 输出物清单

- `layer_stable_inspect_design.md`：稳态巡检体系设计文档（检查清单 / 判定规则 / 分级绑定 / 触发时机）。

## 5. 门禁校验（强制）

> 全部满足才算通过；不通过不得进入 L3-04。

- [ ] 巡检项目完整覆盖架构规定 5 类检查项
- [ ] 偏差分级规则和架构基线保持一致
- [ ] 巡检规则不允许绕过边界门禁

## 6. 更新说明

巡检架构规则变更时同步更新本技能。
