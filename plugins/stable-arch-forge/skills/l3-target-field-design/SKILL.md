# 目标场层设计落地技能

## 1. 架构来源引用

> 引自 `../docs/03_full_detail_design.md`

目标场层承载项目目标、需求、优先级、目标流转。目标结构：ID、标题、描述、优先级、状态、依赖、归属 Agent、验收标准。

- 状态流转：草稿 → 确认 → 分配 → 执行 → 巡检校验 → 完成/驳回。
- 目标拆分规则：大目标拆成子目标，子目标不能跨边界层约束。
- 目标变更：变更必须记录，触发巡检重新评估影响范围。

## 2. 输入条件

- L2 全部技能输出物：`project_global_spec.md`、`boundary_gate_spec.md`

## 3. 分步执行动作

1. 阅读详细设计文档目标场章节。
2. 在 L2 规约与门禁约束范围内，定义项目顶层目标。
3. 将顶层目标拆分为子目标，定义目标属性、状态流转、依赖关系。
4. 自查：目标和子目标不突破边界约束，所有子目标可追溯顶层目标。

## 4. 输出物清单

- `layer_target_field_design.md`：目标场完整设计文档（目标结构 / 状态流转 / 依赖 / 归属）。

## 5. 门禁校验（强制）

> 全部满足才算通过；不通过不得进入 L3-02。

- [ ] 设计全部在 L2 规约、门禁允许范围内
- [ ] 目标结构、状态流转完全对齐架构定义
- [ ] 子目标没有突破边界约束

## 6. 更新说明

架构目标场定义变更时同步更新技能和输出。
